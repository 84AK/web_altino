    어떤 알티노로 할까요?
    
    
    우리 모둠 로봇에 적힌 이름을 보고 골라요. 두 종류는 컴퓨터와 주고받는 말(통신)이 달라서, 맞게 골라야 해요.
    
    
    
      
      
    
    
    
    나중에 위쪽 로봇에서 언제든 바꿀 수 있어요. 헷갈리면 하나 골라 연결해 보세요. 알티노가 답이 없으면 화면에서 알려 줘요.
    
  
    
    


  
    
    
    처음이에요? 3단계면 돼요
    
    
      
      
    1. 1
      가짜 알티노로 연습왼쪽 샘플을 누르고 ▶ 실행. 로봇 없이도 돼요.
      2. 
      
    2. 2
      AI에게 코드 받기① 설명서 복사 → AI 채팅창에 붙여 넣고 원하는 움직임을 말해요.
      3. 
      
    3. 3
      진짜 알티노 연결전원 켜기 → 위쪽 [알티노 연결하기] → 초록 점이면 성공.
      4. 
    
    
    
    알티노가 연결 안 돼도 괜찮아요. 가짜 알티노로 수업할 수 있어요.

    도움말
    


    

    처음이에요? 이 순서대로 해요
    

    알티노가 없어도, 연결이 안 돼도 ①②는 할 수 있어요. 진짜 알티노는 ③부터예요.
    

    ① 가짜 알티노로 연습하기 (연결 없이)
    

      

    1. 왼쪽 샘플 불러오기에서 2. 앞으로 갔다가 멈추기를 눌러요.
      2. 

    2. 코드 칸 아래 ▶ 실행을 눌러요.
      3. 

    3. 오른쪽 아래 알티노 움직임 화면에서 가짜 알티노가 달리는 걸 봐요. [⤢ 크게 보기]로 크게 볼 수 있어요.
      4. 

    

    ② AI에게 코드 받기
    

      

    1. 왼쪽 ① 설명서 복사하기를 눌러요.
      2. 

    2. AI 채팅창에 붙여 넣고(Ctrl+V), 하고 싶은 움직임을 말해요.
      3. 

    3. 받은 코드를 코드 칸에 붙여 넣고 ▶ 실행해서 가짜 알티노로 먼저 시험해요.
      4. 

    

    자세한 대화 순서는 왼쪽 ② 대화 순서 보기에 있어요.
    

    ③ 진짜 알티노 연결하기
    

      

    1. 알티노 전원을 켜요.
      2. 

    2. 컴퓨터 블루투스에서 알티노와 짝짓기를 해요. (처음 한 번만 하면 돼요. 안 되면 연결이 안 될 때를 봐요)
      3. 

    3. 위쪽에서 내 로봇이 알티노인지 알티노 라이트인지 골라요. (처음 열 때 한 번 물어봐요. 나중에 위쪽 단추로 바꿀 수 있어요)
      4. 

    4. 위쪽 [알티노 연결하기]를 누르고, 목록에서 알티노의 COM 포트를 골라요. (맥은 이름이 cu. 로 시작하는 것, 예: cu.ALTINO-1234)
      5. 

    5. 위쪽 상태가 "진짜 알티노 연결됨"(초록 점)으로 바뀌면 성공이에요.
      6. 

    

    ④ 진짜로 달려 보기
    

      

    1. 알티노를 책상 가운데 넓은 곳에 놓아요. 모서리에서 멀리!
      2. 

    2. 처음에는 느리게(바퀴 값 300), 짧게(1~2초) 해요.
      3. 

    3. 이상하면 바로 긴급 정지 버튼이나 Esc 키를 눌러요.
      4. 

    4. 한 대에는 한 사람만 연결할 수 있어요. 모둠에서 순서를 정해요.
      5. 

    

    


    

    명령어 한눈에 보기
    

    맨 위에는 늘 from AltinoLite import * (일반 알티노는 from Altino import *) 와 Open('COM3'), 맨 끝에는 Close() 를 써요. (포트 이름은 웹앱에서는 무시해요)
    

    

    명령하는 일값
    

    Go(왼쪽, 오른쪽)바퀴를 굴려요. 음수는 뒤로-1000 ~ 1000
    

    Steering(값)핸들 꺾기. 0은 직진-127 ~ 127 (+는 오른쪽, -는 왼쪽. 실제 로봇은 확인!)
    

    delay(밀리초)그 시간 동안 하던 일을 계속해요 (1000 = 1초)time.sleep(1) 도 같아요
    

    Sound(값)소리 내기. 0이면 꺼요0 ~ 255 (소리 높이 [확인 필요])
    

    Light(값)불빛 켜기. 0이면 꺼요0 ~ 255 (켜지는 곳 [확인 필요])
    

    Display('A')알티노 화면에 글자 보이기. 0이면 꺼요글자 하나
    

    Stop()바퀴·핸들·소리·불빛을 한꺼번에 끄기
    

    sensor.IR[1] ~ [6]적외선 센서. 앞 물체가 가까울수록 큰 값일 가능성이 커요 [확인 필요]숫자
    

    

    센서를 읽기 전에 SensorFun(0) 으로 새 값을 받아와요. 예: sensor = SensorFun(0) 다음 print(sensor.IR[2]).
    

    from AltinoLite import *
Open('COM3')
Go(500, 500)      # 앞으로
delay(1500)       # 1.5초 동안
Stop()            # 멈춤
Close()
    

    🔇 소리를 켰다면 꼭 Sound(0) 으로 꺼요. 한 번 켜면 계속 울려요.
    

    


    

    AI와 대화해서 코드 받기 (4단계)
    

    AI(챗GPT, 제미나이, 클로드 등)는 알티노 명령어를 몰라요. 그래서 먼저 설명서를 주고, 그다음에 하고 싶은 걸 말해요.
    

    파일로 받기
    

    ① 설명서를 AI에게 붙여 넣기
    

    위 버튼을 누르고, AI 채팅창에 붙여 넣기(Ctrl+V) 한 뒤 보내요. AI가 "설명서를 읽었어요! 어떤 움직임을 하면 좋겠어요?" 라고 하면 성공이에요.
    

    다른 대답을 하면 이렇게 말해요.
    

    설명서를 읽고, 안내한 대로만 대답해 줘.
    

    ② 하고 싶은 움직임 말하기
    

    알티노가 [예: 네모 모양으로 한 바퀴 돌고 멈추게] 해 줘. 천천히, 안전하게.
    

    AI가 되물으면 짧게 답해요. (예: "2초 동안, 오른쪽으로 돌아요")
    

    ③ 받은 코드 실행하기
    

      

    1. AI가 준 코드 블록 전체를 복사해요.
      2. 

    2. 왼쪽 코드 칸에 붙여 넣어요 (기존 코드는 지워도 돼요).
      3. 

    3. 먼저 가짜 알티노로 [▶ 실행]을 눌러 움직임 화면을 보고 확인해요.
      4. 

    4. 마음에 들면 진짜 알티노를 연결하고 다시 실행해요.
      5. 

    

    웹앱에서는 코드 속 COM4 같은 포트 이름을 신경 쓰지 않아도 돼요.
    

    ④ 이상하면 AI에게 다시 말하기
    

    생각과 다르게 움직일 때
    

    방금 코드에서 [예: 너무 빨라 / 오른쪽 대신 왼쪽으로 돌았어]. 바꿔 줘. 바뀐 줄이 어디인지도 알려 줘.
    

    빨간 오류가 났을 때
    

    이 코드를 실행했더니 아래 오류가 났어. 쉬운 말로 이유를 알려 주고, 고친 코드를 줘.
[결과 창의 빨간 글자를 복사해서 붙이기]
    

    센서를 쓰고 싶을 때
    

    sensor.IR[2] 값이 [예: 500] 보다 커지면 멈추고 소리를 내는 코드를 만들어 줘. 소리는 마지막에 꼭 꺼 줘.
    

    🔇 소리는 한 번 켜면 계속 울려요. AI가 준 코드에 Sound(0) 이 없으면 넣어 달라고 해요.
    

    


    

    연결이 안 될 때 (증상으로 찾기)
    

    코드 연습은 연결 없이도 돼요. 가짜 알티노가 대신 움직여요. 진짜 알티노를 움직일 때만 아래를 봐요.
    


    처음 한 번: 블루투스 짝짓기
    

      

    1. 알티노 전원을 켜요.
      2. 

    2. 윈도우 설정 → 블루투스 및 장치에서 알티노를 찾아 연결해요. (비밀번호는 보통 1234 또는 0000 [확인 필요])
      3. 

    3. 짝짓기를 하면 윈도우가 COM 포트(알티노 전용 길)를 만들어 줘요. 장치 관리자 → 포트(COM & LPT)에서 볼 수 있어요.
      4. 

    


    ① [알티노 연결하기]가 안 눌려요 / 아무 일도 없어요
    

    브라우저가 크롬(Chrome) 또는 엣지(Edge)가 맞는지 봐요. 다른 브라우저(사파리, 파이어폭스)는 지원하지 않아요.
    


    ② 목록이 비어 있어요
    

    알티노 전원이 켜져 있는지, 윈도우에서 짝짓기가 되어 있는지 확인해요. 짝짓기가 안 돼 있으면 COM 포트도 없어요.
    


    ③ 목록에 COM 포트가 여러 개예요
    

    알티노 이름이 붙은 포트를 골라요. 포트가 둘이면 한쪽이 안 될 수 있어요. 안 되면 다른 쪽을 눌러 봐요. 맥에서는 cu. 로 시작하는 쪽(예: cu.ALTINO-1234)을 골라요.
    


    ⑦ 연결은 됐는데 "알티노에게서 답이 없어요"라고 나와요
    

    앱이 먼저 스스로 연결을 두 번 다시 시도해요. 그래도 안 되면 이 순서로 해요.
    

      

    1. 위쪽에서 고른 로봇 종류(알티노 / 알티노 라이트)가 실제 로봇과 같은지 봐요.
      2. 

    2. 알티노 전원을 껐다가 켜요. 다른 컴퓨터가 먼저 연결했던 로봇은 이렇게 해야 풀려요.
      3. 

    3. [가짜 알티노로 연습]을 눌러 연결을 끊어요.
      4. 

    4. 페이지를 새로고침(F5)하고 다시 [알티노 연결하기]를 눌러요.
      5. 

    

    로봇 한 대는 한 번에 한 컴퓨터만 연결돼요. 사람이 바뀔 때마다 연결 끊기 → 로봇 전원 껐다 켜기를 해요.
    


    ④ "열 수 없어요"라고 나와요
    

    다른 프로그램이 같은 포트를 쓰고 있어요. IDLE이나 다른 탭의 이 웹앱을 닫아요. 한 대에는 한 사람(한 화면)만 연결돼요.
    

    다른 노트북이나 폰이 먼저 연결해 둔 경우도 같아요. 로봇은 한 번에 한 기기만 잡을 수 있어요.
    

    맥에서 누가 잡고 있는지 보려면 터미널에 lsof /dev/cu.ALTINO-1234 (이름은 내 로봇에 맞게)를 쳐요. 나온 프로그램을 닫으면 돼요.
    


    ⑧ 계속 안 될 때: 블루투스 처음부터 다시 (마지막 방법)
    

    컴퓨터에 옛 연결 흔적이 남아서 꼬일 때가 있어요. 아래 순서대로, 순서를 지켜서 해요.
    

    윈도우
    

      

    1. 이 웹앱의 연결을 끊고 크롬 탭을 닫아요. (IDLE 등 다른 프로그램도 닫기)
      2. 

    2. 설정 → 블루투스 및 장치에서 알티노 옆 ⋯ → 장치 제거를 해요.
      3. 

    3. 컴퓨터 블루투스를 끄고, 10초 뒤 다시 켜요.
      4. 

    4. 알티노 전원을 껐다가 켜요.
      5. 

    5. 장치 추가로 알티노를 다시 짝짓기해요.
      6. 

    6. 장치 관리자 → 포트(COM & LPT)에서 알티노 COM 포트가 생겼는지 봐요. 둘이 보이면 보통 "나가는(Outgoing)" 쪽이 맞아요. 안 되면 다른 쪽을 써요.
      7. 

    

    맥
    

      

    1. 이 웹앱의 연결을 끊고 크롬 탭을 닫아요. (IDLE 등 다른 프로그램도 닫기)
      2. 

    2. 시스템 설정 → 블루투스에서 알티노 옆 ⓘ → 이 기기 지우기를 해요.
      3. 

    3. 메뉴 막대에서 블루투스를 끄고, 10초 뒤 다시 켜요.
      4. 

    4. 알티노 전원을 껐다가 켜요.
      5. 

    5. 블루투스 목록에서 알티노를 다시 연결해요. (확인 숫자가 잠깐 나오면 그대로 허용)
      6. 

    6. 터미널에 ls /dev/cu.ALTINO* 를 쳐서 이름이 나오면 준비 끝이에요. 안 나오면 2~5를 한 번 더 해요.
      7. 

    

    그래도 안 되면 [가짜 알티노로 연습]으로 수업을 계속하고, 선생님께 알려요.
    


    ⑤ 연결은 됐는데 알티노가 안 움직여요
    

      

    1. 코드에 Open(...)이 있는지, Go(300, 300) 다음에 delay(1500)가 있는지 봐요.
      2. 

    2. 알티노 배터리가 충분한지 봐요.
      3. 

    3. [가짜 알티노로 연습]을 눌러 연결을 끊고, 알티노 전원을 껐다 켠 뒤 다시 연결해요.
      4. 

    


    ⑥ 이상하게 움직이거나 멈추지 않아요
    

    바로 긴급 정지(또는 Esc 키)를 눌러요. 그래도 안 멈추면 알티노 전원을 꺼요.
    

    소리가 계속 나면 Sound(0)을 실행해요.
    

    


    

    낯선 말 풀이
    

    

    말쉬운 뜻
    

    블루투스 짝짓기컴퓨터와 알티노가 서로 "내 친구야" 하고 등록하는 일이에요. 처음 한 번만 해요.
    

    COM 포트컴퓨터와 알티노 사이의 전용 길 이름이에요. 예: COM4. 짝짓기하면 윈도우가 만들어 줘요.
    

    가짜 알티노화면 속에서 대신 달리는 연습용 알티노예요. 진짜 알티노 없이도 코드를 시험할 수 있어요.
    

    긴급 정지모든 움직임·소리·불빛을 바로 끄는 비상 단추예요. Esc 키도 같아요.
    

    delay(1000)"1초 동안 지금 하던 걸 계속해"라는 뜻이에요. 1000밀리초 = 1초예요.
    

    센서 값알티노 눈(적외선)이 읽은 숫자예요. 보통 앞에 물체가 가까울수록 커요 [확인 필요].
    

    바퀴 값-1000 ~ 1000. 클수록 빨라요. 마이너스는 뒤로 가요.
