    도움말
    


    

    명령어 한눈에 보기
    

    맨 위에는 늘 from AltinoLite import * 와 Open('COM3'), 맨 끝에는 Close() 를 써요. (포트 이름은 웹앱에서는 무시해요)
    

    

    명령하는 일값
    

    Go(왼쪽, 오른쪽)바퀴를 굴려요. 음수는 뒤로-1000 ~ 1000
    

    Steering(값)핸들 꺾기. 0은 직진-127 ~ 127 (왼/오 방향은 직접 확인)
    

    delay(밀리초)그 시간 동안 하던 일을 계속해요 (1000 = 1초)time.sleep(1) 도 같아요
    

    Sound(값)소리 내기. 0이면 꺼요0 ~ 255 (소리 높이 [확인 필요])
    

    Light(값)불빛 켜기. 0이면 꺼요0 ~ 255 (켜지는 곳 [확인 필요])
    

    Display('A')알티노 화면에 글자 보이기. 0이면 꺼요글자 하나
    

    Stop()바퀴·핸들·소리·불빛을 한꺼번에 끄기
    

    sensor.IR[1] ~ [6]적외선 센서. 앞 물체가 가까울수록 큰 값일 가능성이 커요 [확인 필요]숫자
    

    

    센서를 읽기 전에 SensorFun(0) 으로 새 값을 받아와요. 예: sensor = SensorFun(0) 다음 print(sensor.IR[2]).
    

    from AltinoLite import *
Open('COM3')
Go(500, 500)      # 앞으로
delay(1500)       # 1.5초 동안
Stop()            # 멈춤
Close()
    

    🔇 소리를 켰다면 꼭 Sound(0) 으로 꺼요. 한 번 켜면 계속 울려요.
    

    


    

    AI에게 물어볼 말 모음
    

    아래 글을 통째로 복사해서 AI(챗GPT, 제미나이, 클로드 등)에 붙여 넣고, 맨 끝 [ ] 부분만 내 생각으로 바꿔요.
    

    ① 첫 번째 질문 (꼭 붙이기)
    

    파이썬 초보자야. 알티노 라이트 로봇을 움직이는 코드를 만들어 줘.
규칙:
1. 맨 위에 from AltinoLite import * 와 Open('COM3') 를 쓰고, 맨 끝에 Close()
2. 쓸 수 있는 명령은 Go(왼쪽,오른쪽) -1000~1000, Steering(-127~127), delay(밀리초), Sound(0~255), Light(0~255), Stop() 뿐이야
3. 센서는 sensor.IR[1]~[6] 로 읽어
4. 다른 라이브러리는 쓰지 마
5. 코드에 한국어 주석을 달아 줘
6. 끝나기 전에 Stop() 으로 멈추게 해 줘
만들고 싶은 움직임: [예: 네모 모양으로 한 바퀴 돌기]
    

    ② 고치고 싶을 때
    

    방금 코드에서 [예: 더 천천히 / 더 크게 돌게] 바꿔 줘. 바뀐 줄이 어디인지도 알려 줘.
    

    ③ 오류가 났을 때
    

    이 코드를 실행했더니 아래 오류가 났어. 쉬운 말로 이유를 알려 주고, 고친 코드를 줘.
[결과 창의 빨간 글자를 복사해서 붙이기]
    

    ④ 센서를 쓰고 싶을 때
    

    sensor.IR[2] 값이 [예: 500] 보다 커지면 멈추고 소리를 내는 코드를 만들어 줘. 소리는 마지막에 꼭 꺼 줘.
    

    


    

    연결이 안 될 때
    

    코드 연습은 연결 없이도 돼요. 화면의 가짜 알티노가 대신 움직여요. 진짜 알티노를 움직일 때만 아래를 확인해요.
    

      

    1. 브라우저는 크롬(Chrome) 또는 엣지(Edge)여야 해요. 다른 브라우저는 연결 단추가 안 돼요.
      2. 

    2. 알티노 전원을 켜요.
      3. 

    3. 윈도우 블루투스 설정에서 알티노를 한 번 짝지어요 (비밀번호는 보통 1234 또는 0000 [확인 필요]).
      4. 

    4. 짝지으면 윈도우가 COM 포트를 만들어 줘요. 장치 관리자 → 포트(COM & LPT)에서 확인해요.
      5. 

    5. [알티노 연결하기]를 누르고 목록에서 알티노가 만든 COM 포트를 골라요. 포트가 둘이면 다른 쪽도 눌러 봐요.
      6. 

    6. IDLE 같은 다른 프로그램이 같은 포트를 쓰고 있으면 열리지 않아요. 그 프로그램을 닫아요.
      7. 

    7. 한 대에는 한 사람만 연결해요. 3명이 동시에 연결할 수 없어요. 모둠 순서를 정해요.
      8. 

    8. 이상하게 움직이면 위쪽 긴급 정지(또는 Esc 키)를 눌러요.
      9. 

    

    그래도 안 되면 [가짜 알티노로 연습]을 눌러 연결을 끊고, 알티노 전원을 껐다 켜고 다시 해 봐요.
